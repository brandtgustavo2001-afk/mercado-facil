# Mercado Fácil 1.0.5 — compras organizadas e histórico

- Produtos pendentes aparecem primeiro; itens marcados ficam reunidos na seção **Selecionados** abaixo.
- O botão **Comprados** fica visível na parte inferior da tela quando há itens selecionados. Use após pagar para registrar a compra.
- Os itens pagos saem da lista atual; os itens ainda pendentes continuam disponíveis.
- Nova aba **Histórico** mostra os produtos e valores de cada compra e guarda somente as 10 compras mais recentes. Compras mais antigas são excluídas automaticamente.
- Atualização do banco de dados com preservação das listas existentes e dos itens já selecionados.
- Backup JSON agora inclui as compras recentes; arquivos de backup antigos continuam compatíveis.

O histórico de compras é local neste aparelho. Em listas compartilhadas, a retirada dos itens pagos sincroniza com os outros participantes, mas os registros do histórico não são compartilhados.

Atualize pelo aviso do aplicativo ou em **Configurações → Verificar atualizações**. O Android precisa confirmar a instalação.
