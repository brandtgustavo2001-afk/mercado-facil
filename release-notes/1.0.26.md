# 1.0.26

- Permite vincular cada rotina de injeção a uma lista compartilhada específica. Apenas os participantes dessa lista recebem a rotina e o histórico; proprietário/editor pode editar, leitor apenas consulta.
- Rotinas já cadastradas continuam privadas até serem vinculadas. É possível mudar a lista ou voltar a deixar os dados privados; a rotina é recriada com novos identificadores para impedir ressurreição dos dados no grupo anterior.
- Sincroniza rotina, calendário, próximos intervalos e registros de aplicação entre instalações.
- Lembretes são configurados por aparelho e não alteram as preferências de notificação dos outros participantes.
- Migração Room 5→6 preserva os dados locais e a fila de sincronização.
- Requer executar `supabase/migrations/202611080001_shared_injections.sql` no projeto Supabase existente para habilitar a sincronização compartilhada. Enquanto a migração não for aplicada, as compras continuam sincronizando e as alterações de injeção ficam pendentes localmente.
