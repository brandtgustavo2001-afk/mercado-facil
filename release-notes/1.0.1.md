# Mercado Fácil 1.0.1 — conexão com Supabase

- Projeto Supabase configurado automaticamente no aplicativo, usando somente URL e chave pública publishable.
- Banco com oito tabelas protegidas por RLS e três tabelas publicadas no Realtime.
- Corrigido um identificador reservado que impedia aplicar a migração SQL inicial.
- Reforçada a validação dos campos recebidos pelas RPCs.
- Testes SQL passaram no Supabase real: idempotência, merges independentes, conflitos, compra compartilhada, visualizador, participante removido, convites revogados/expirados e tombstones. Nenhum registro temporário permaneceu.
- Vinte testes Android/JVM passaram e Android Lint terminou sem erros.

Instale este APK sobre a versão 1.0.0 assinada. Não é necessário desinstalar. A versão usa a mesma chave e o mesmo esquema Room, com versionCode crescente (10000 → 10001).

Em Ajustes, crie uma conta do aplicativo e confirme o e-mail. O login usado para administrar o painel Supabase pelo GitHub não cria automaticamente uma conta no aplicativo.

Pré-release para testes. O fluxo Android em dois aparelhos, a entrega de e-mails para participantes e a atualização instalada ainda precisam ser validados. Veja STATUS.md para o restante do escopo.
